## How to Return to Your GitHub Codespace

Follow these steps to go back to your GitHub Codespace:

1. **Go to [github.com](https://github.com)** and sign in to your account.
2. **Open your Codespaces list** using one of these methods:
   - Click your **profile avatar** (top-right corner) → select **"Your codespaces"**
   - Or navigate directly to **[github.com/codespaces](https://github.com/codespaces)**
3. **Find your codespace** for this repository in the list.
4. Click the **"Open"** button (or the codespace name) to resume it in your browser.

> **Tip:** You can also reopen a codespace directly from the repository page by clicking the green **"Code"** button → **"Codespaces"** tab → select your existing codespace.
